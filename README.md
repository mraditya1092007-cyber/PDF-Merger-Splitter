## Project Scope

This project is a Python-based PDF utility tool that allows users to perform common PDF operations through a simple console interface.

It supports:

- PDF Merging
- PDF Splitting
- Text Extraction
- PDF Information Viewer

---

## Project Description

PDF-Merger-Splitter is a Python console application developed using the PyPDF2 library.

The program enables users to manage PDF files efficiently by providing multiple useful features in a single tool.

---

## Features

1. Merge PDF Files
2. Split PDF into Separate Pages
3. Extract Text from PDF
4. View PDF Information
5. Exit Program

## Sample Features

### PDF Info

Displays:

- Total Pages
- Title
- Author
- Creator

### Extract Text

Extracts text from PDF and saves it into:

`extracted_text.txt`

### Split PDF

Splits PDF into separate pages:

```text
page_1.pdf
page_2.pdf
page_3.pdf
```
