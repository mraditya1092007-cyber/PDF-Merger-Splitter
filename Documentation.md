# PDF Merger & Splitter Documentation

## Project Title

PDF Merger & Splitter

---

## Objective

The objective of this project is to provide a simple Python-based PDF utility tool that allows users to perform common PDF operations such as merging PDF files, splitting PDF files, extracting text from PDFs, and viewing PDF information.

---

## Description

PDF Merger & Splitter is a console-based application developed using Python and the PyPDF2 library.

The application helps users manage PDF documents without using any external software. Users can easily merge multiple PDF files, split PDFs into individual pages, extract text content, and view document metadata.

---

## Features

### 1. Merge PDF

Combines two PDF files into a single PDF document.

### 2. Split PDF

Splits a PDF file into separate pages and saves each page as an individual PDF file.

### 3. Extract Text

Extracts text from all pages of a PDF document and saves it into a text file.

### 4. PDF Information

Displays useful information about the PDF including:

- Total Pages
- Title
- Author
- Creator

### 5. Exit

Closes the application.


## Working Process

1. Launch the application.
2. Select an operation from the menu.
3. Enter the PDF file path.
4. The selected operation will be performed.
5. Output files will be saved automatically.
